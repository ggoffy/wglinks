# wgLinks module for  [XOOPS CMS 2.5.12+](https://xoops.org)

![module image](./assets/images/wglinks.jpg)

**wgLinks** is a module for [XOOPS CMS](https://xoops.org) that allows you to create, manage, and display collections of website links. It provides a straightforward way to organize useful online resources into categories and make them accessible to visitors through your website.

Whether you want to share useful websites, provide links to partner organizations, or build a directory of online resources, wgLinks offers a flexible solution for maintaining and presenting your link collections.

## Features

- **Category management:** Organize links into meaningful categories to make collections easier to navigate.
- **Flexible presentation:** Display link collections using the templates provided by the module.
- **Responsive layouts:** Most front-end templates are designed to adapt to different screen sizes.
- **Template options:** Different templates are included (e.g. Bootstrap Cards).
- **Bootstrap compatibility:** Use a Bootstrap-based XOOPS theme for proper front-end presentation.
- **Centralized administration:** Manage your link collections through the XOOPS administration interface.

## Requirements

- XOOPS CMS 2.7.4 or higher
- XOOPS Admin 1.2
- PHP 8.4 or higher
- MySQL 5.7.8 or higher (MySQL 8.4.5 or higher recommended)
- A Bootstrap-based theme for the recommended front-end presentation

## Installation

1. Download the wgLinks module package.
2. Extract the package into the `modules` directory of your XOOPS installation.
3. Open the XOOPS administration area and navigate to the module management section.
4. Install wgLinks or update the existing installation.
5. Configure the module and create categories for your link collections.
6. Add your links, assign them to the appropriate categories, and review their presentation on the front end.

Before upgrading an existing installation, back up your database and module files.
