Hilfe: wgLinks

wgLinks

Linksammlungen für XOOPS

Erstellen und organisieren Sie Sammlungen nützlicher Website-Links mithilfe von Kategorien und präsentieren Sie diese Ihren Besuchern mit den vom Modul bereitgestellten Vorlagen.

XOOPS 2.7.4+ · PHP 8.4+

Willkommen

Willkommen auf der Hilfeseite von wgLinks. Dieses Modul bietet eine einfache Möglichkeit, Linksammlungen auf Ihrer XOOPS-Website zu veröffentlichen und zu organisieren.

Mithilfe von Kategorien können thematisch zusammengehörige Ressourcen gruppiert werden. Das Erscheinungsbild im Frontend hängt von den Vorlagen und Optionen ab, die in Ihrer installierten Version verfügbar sind.

Die meisten Vorlagen für die Benutzeroberfläche sind responsiv. Für eine korrekte Darstellung empfiehlt das Projekt die Verwendung eines auf Bootstrap basierenden Themes.
Tipp: Verwenden Sie aussagekräftige Linktitel, ordnen Sie jeden Link der passendsten Kategorie zu und überprüfen Sie regelmäßig, ob externe URLs noch gültig sind.

Installation und Voraussetzungen

Installieren Sie wgLinks über die standardmäßige Modulverwaltung von XOOPS. Erstellen Sie vor einem Upgrade eine Sicherungskopie Ihrer Datenbank und der aktuellen Moduldateien.

Komponente Voraussetzung
XOOPS CMS Version 2.7.4 oder höher
XOOPS Admin Version 1.2
PHP Version 8.4 oder höher
MySQL Version 5.7.8 oder höher; empfohlen wird Version 8.4.5 oder höher
  1. Laden Sie das Modulpaket herunter und entpacken Sie es.
  2. Laden Sie das Modulverzeichnis in das Verzeichnis modules Ihrer XOOPS-Installation hoch.
  3. Installieren oder aktualisieren Sie das Modul über die XOOPS-Modulverwaltung.
  4. Öffnen Sie die Administration von wgLinks und überprüfen Sie die Konfiguration.
Vor einem Upgrade: Sichern Sie die Datenbank und das Modulverzeichnis und beachten Sie alle versionsspezifischen Hinweise, die der jeweiligen Veröffentlichung beiliegen.

Erste Schritte

Öffnen Sie nach der Installation von wgLinks das Modul im Administrationsbereich von XOOPS. Die genauen Bezeichnungen und verfügbaren Aktionen können je nach Modulversion variieren.

  1. Öffnen Sie Administration → Module.
  2. Öffnen Sie wgLinks.
  3. Erstellen Sie Kategorien, um Ihre Linksammlung zu organisieren.
  4. Sortieren Sie die Kategorien per Drag-and-drop.
  5. Fügen Sie Links hinzu und ordnen Sie diese den passenden Kategorien zu.
  6. Sortieren Sie die Links per Drag-and-drop.
  7. Öffnen Sie die öffentliche Modulansicht und überprüfen Sie das Ergebnis.
Empfohlene Vorgehensweise: Erstellen Sie zunächst die Kategorienstruktur. Fügen Sie anschließend Links mit aussagekräftigen Titeln, korrekten Ziel-URLs und – sofern unterstützt – hilfreichen Beschreibungen hinzu.

Kategorien verwalten

Kategorien sind das wichtigste Mittel, um Links in wgLinks zu organisieren. Verwenden Sie sie, um thematisch zusammengehörige Websites, Dienste, Organisationen oder andere Online-Ressourcen zu gruppieren.

Empfehlungen

  • Wählen Sie kurze und aussagekräftige Kategorienamen.
  • Halten Sie die Kategorienstruktur für Besucher übersichtlich und verständlich.
  • Vermeiden Sie mehrere Kategorien mit demselben Zweck.
  • Überprüfen Sie die Kategoriezuordnung, wenn sich das Thema oder der Zweck eines Links ändert.
Die Projektbeschreibung nennt die Unterstützung von Kategorien als Kernfunktion. Welche Kategorienfelder und Aktionen verfügbar sind, erfahren Sie in den Administrationsansichten Ihrer installierten Version.

Links verwalten

Verwenden Sie den Administrationsbereich des Moduls, um die Links Ihrer Sammlung zu verwalten. Die verfügbaren Felder und Aktionen hängen von der installierten Version ab.

Links hinzufügen oder bearbeiten

  • Titel: Verwenden Sie einen prägnanten Namen, der das Linkziel eindeutig beschreibt.
  • URL: Geben Sie die vollständige Zieladresse ein und überprüfen Sie deren Funktion.
  • Kategorie: Wählen Sie die Kategorie, die am besten zur Ressource passt.
  • Beschreibung: Erläutern Sie kurz, was Besucher dort finden, sofern dieses Feld verfügbar ist.

Linksammlung pflegen

  • Korrigieren Sie URLs, deren Adresse sich geändert hat.
  • Entfernen Sie Links, die nicht mehr relevant oder verfügbar sind.
  • Aktualisieren Sie Titel und Beschreibungen, wenn sich eine Website verändert.
  • Überprüfen Sie externe Links regelmäßig, da andere Websites umziehen oder offline gehen können.
Wichtig: Überprüfen Sie Ziel-URLs, bevor Sie sie veröffentlichen. Ein Link kann syntaktisch korrekt sein und dennoch zu einer nicht vorhandenen Seite oder einem unerwarteten Ziel führen.

Vorlagen und Theme

Die öffentlichen Seiten des Moduls werden mithilfe von XOOPS-Vorlagen dargestellt. Die meisten Vorlagen für die Benutzeroberfläche sind responsiv. Für eine korrekte Darstellung empfiehlt das Projekt jedoch ein Bootstrap-Theme.

Wenn die Darstellung nicht korrekt ist

  • Prüfen Sie, ob das aktive XOOPS-Theme mit Bootstrap kompatibel ist.
  • Überprüfen Sie die verfügbaren Vorlagenoptionen des Moduls.
  • Leeren Sie nach Änderungen an Vorlagen oder Theme-Dateien die entsprechenden XOOPS-Caches.
  • Prüfen Sie die Darstellung sowohl auf Desktop- als auch auf Mobilgeräten.

Berechtigungen

Konfigurieren Sie den Zugriff über die XOOPS-Gruppenverwaltung und die Modulberechtigungen, die in Ihrer Installation verfügbar sind.

  • Gewähren Sie nur vertrauenswürdigen Gruppen Zugriff auf die Moduladministration.
  • Überprüfen Sie die Berechtigungen, wenn Administratoren oder Besucher erwartete Inhalte nicht sehen können.
  • Testen Sie das Modul nach einer Änderung der Berechtigungen mit einem Benutzerkonto, das der betreffenden Gruppe angehört.
Sicherheitsempfehlung: Gewähren Sie Bearbeitungs- und Löschrechte nur Benutzern, die für die Pflege der Linksammlung verantwortlich sind.

Fehlerbehebung

Die Modulseite wird nicht korrekt angezeigt

  • Prüfen Sie, ob das aktive Theme mit Bootstrap kompatibel ist.
  • Überprüfen Sie die ausgewählte Vorlage und die verfügbaren Optionen.
  • Leeren Sie den XOOPS-Cache und laden Sie die Seite erneut.

Ein Link wird nicht angezeigt

  • Vergewissern Sie sich, dass der Link erfolgreich gespeichert wurde.
  • Überprüfen Sie die Kategorie sowie gegebenenfalls verfügbare Sichtbarkeits- und Zugriffseinstellungen.
  • Kontrollieren Sie die XOOPS-Gruppenberechtigungen.

Eine Ziel-URL funktioniert nicht

  • Kopieren Sie die URL in einen Browser und testen Sie sie direkt.
  • Prüfen Sie auf Tippfehler, Weiterleitungen oder veraltete Adressen.
  • Aktualisieren oder entfernen Sie den Link, wenn das Ziel nicht mehr verfügbar ist.

Probleme bei der Installation oder Aktualisierung

  • Stellen Sie sicher, dass der Server die unten aufgeführten Voraussetzungen erfüllt.
  • Prüfen Sie die XOOPS- und PHP-Fehlerprotokolle auf weitere Hinweise.
  • Lesen Sie die README-Datei und die Versionshinweise der installierten Version.
