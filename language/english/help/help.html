Help: wgLinks

wgLinks

Link collections for XOOPS

Create and organize collections of useful website links with categories and display them to visitors using the templates provided by the module.

XOOPS 2.7.4+ · PHP 8.4+

Welcome

Welcome to the wgLinks help page. This module provides a simple way to publish and organize link collections on your XOOPS website.

Categories help group related resources together. The front-end appearance depends on the templates and options available in your installed version.

Most user-side templates are responsive. The project recommends using a Bootstrap-based theme for proper display.
Tip: Keep link titles descriptive, place each link in the most suitable category, and periodically check that external URLs are still valid.

Installation & Requirements

Install wgLinks using the standard XOOPS module administration workflow. Before upgrading, back up your database and the current module files.

Component Requirement
XOOPS CMS 2.7.4 or higher
XOOPS Admin 1.2
PHP 8.4 or higher
MySQL 5.7.8 or higher; 8.4.5 or higher recommended
  1. Download and extract the module package.
  2. Upload the module directory to your XOOPS modules directory.
  3. Install or update the module through XOOPS module administration.
  4. Open wgLinks administration and verify the configuration.
Before upgrading: Back up the database and module directory, and follow any version-specific instructions included in the release.

Getting Started

After installing wgLinks, open the module from the XOOPS administration area. The exact names and available actions may vary between module versions.

  1. Open Administration → Modules.
  2. Open wgLinks.
  3. Create categories to organize your link collection.
  4. Sort the categories by drag&drop.
  5. Add links and assign them to the appropriate categories.
  6. Sort the links by drag&drop.
  7. Open the public-facing module page and check the result.
Recommended workflow: Create your category structure first, then add links with clear titles, correct destination URLs, and useful descriptions where supported.

Managing Categories

Categories are the main way to organize links in wgLinks. Use them to group related websites, services, organizations, or other online resources.

Recommended practices

  • Choose short, meaningful category names.
  • Keep the category structure easy for visitors to understand.
  • Avoid creating several categories that serve the same purpose.
  • Review category assignments when a link changes topic or purpose.
The repository identifies category support as a core feature. Refer to the administration screens in your installed version for the available category fields and actions.

Managing Links

Use the module's administration area to maintain the links in your collection. Available fields and actions depend on the installed version.

When adding or editing a link

  • Title: use a concise name that clearly identifies the destination.
  • URL: enter and test the complete destination address.
  • Category: select the category that best matches the resource.
  • Description: if available, explain briefly what visitors will find there.

Maintaining the collection

  • Correct URLs that have changed.
  • Remove links that are no longer relevant or available.
  • Update titles and descriptions when a website changes.
  • Check external links periodically; other websites may move or go offline.
Important: Test destination URLs before publishing them. A link can be syntactically valid but still lead to a missing page or an unexpected destination.

Templates and Theme

The module's public pages are rendered using XOOPS templates. Most user-side templates are responsive, but the project recommends a Bootstrap theme for correct presentation.

If the display does not look right

  • Check that the active XOOPS theme is compatible with Bootstrap.
  • Review the module's available template options.
  • After changing templates or theme files, clear the relevant XOOPS caches.
  • Check the page at desktop and mobile widths.

Permissions

Configure access through the XOOPS group and module permission controls available in your installation.

  • Give module administration access only to trusted groups.
  • Check permissions when an administrator or visitor cannot see expected content.
  • After changing permissions, test the module while logged in as a member of the relevant group.
Security recommendation: Grant editing and deletion rights only to users who are responsible for maintaining the link collection.

Troubleshooting

The module page does not display correctly

  • Check whether the active theme is Bootstrap-compatible.
  • Check the selected template and its available options.
  • Clear the XOOPS cache and reload the page.

A link is missing

  • Confirm that the link was saved successfully.
  • Check its category and any visibility or access controls available in your version.
  • Review XOOPS group permissions.

A destination URL does not work

  • Copy the URL into a browser and test it directly.
  • Check for typing errors, redirects, or an obsolete address.
  • Update or remove the link if the destination is no longer available.

Installation or update problems

  • Verify that the server meets the requirements listed below.
  • Check the XOOPS and PHP error logs for details.
  • Consult the README and release notes for the version you installed.
